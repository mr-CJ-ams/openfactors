# Release checklist

The checklist is one local command: `python -m openfactors.orchestration.accept`. It is not an HTTP route. It prints go or no-go from the records already in this repository. It does not write a signature, fill a QA status, or set a production version.

The decision is no-go. The product owner confirmed the five cities on 2026-10-25. Holiday years 2018 through 2026 are transcribed. The ERA5 responses for 2018-01-01 through 2026-10-25 are stored. The archive left 2026-10-20 through 2026-10-25 null. Date span and rate numbers remain unset. Hosted recovery-time targets remain unset. The hosted load profile is not signed off. Public hosting is not approved. There is no paging service. Release-blocking QA cases remain not run. Residual risks, the rollback plan, and a production version are not signed.

Two records are already present and do not change the decision. The source registry allows redistribution for this non-commercial baseline, and the export caps are 100,000 rows and 50 MB.
